## Opt-in instructions (send to testers)

1. Open the **Play Console closed-test opt-in link** (not a sideload APK).
2. Accept the test with the **same Google account** that was invited.
3. Install **Texta** from the Play Store testing track.
4. Stay opted in for **at least 14 days**.
5. Use the app: create a notebook, create/edit a note, force-quit and reopen to confirm persistence.
6. Send feedback to: _your feedback channel_.
